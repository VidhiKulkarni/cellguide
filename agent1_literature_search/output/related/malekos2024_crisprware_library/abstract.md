# CRISPRware: an efficient method for contextual gRNA library design

Malekos E. et al., *bioRxiv* preprint (2024). PMC11213142, DOI 10.1101/2024.06.18.599405

The authors present CRISPRware, a Python software package for generating guide RNA libraries for CRISPR experiments targeting protein-coding regions, noncoding elements, and translated regions across multiple CRISPR modalities. The tool leverages next-generation sequencing data to design context-specific gRNAs while accounting for genetic variation, enabling allele-specific guide design on a genome-wide scale. CRISPRware integrates established on-target and off-target scoring methods and has been validated across multiple model organisms.
