# Agent 2 structured extraction — kumbara2025_crispr_hawk

1. **Experimental design**: Computational — variant-aware guide design tool (CRISPR-HAWK).
2. **Target genes**: BCL11A + 7 other therapeutic loci; evaluated across 79,648 human genomes (population variant data).
3. **Outcomes**: On-target — activity altered by population variants in 82.5% of guides. Off-target — PAM creation/loss events flagged as a specificity risk source not captured by reference-genome-only design.
4. **Data type**: Population genomic variant data; no wet-lab cell system.
