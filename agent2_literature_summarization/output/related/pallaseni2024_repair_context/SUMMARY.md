# Agent 2 structured extraction — pallaseni2024_repair_context

1. **Experimental design**: KO/cleavage — mechanistic dissection of DNA repair pathway choice after Cas9 cutting, using repair-gene knockout mESC lines.
2. **Target genes**: Synthetic reporter target sites (not endogenous genes); repair genes studied: Prkdc, Polm, Nbn, Polq.
3. **Outcomes**: On-target — 236,000+ mutational outcomes characterized; shows how repair-pathway usage (and thus resulting indel spectrum) is biased by target sequence context and repair-gene status. Off-target — not addressed.
4. **Data type**: 18 repair-deficient mouse embryonic stem cell (mESC) lines.
